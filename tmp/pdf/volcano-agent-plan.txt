1. 套餐概览
方舟 Agent Plan 是面向个人用户推出的订阅式大模型服务套餐包，新增支持全模态模型及专属 Harness，
采用精细化积分计费模式，助力开启 Agent 场景的全新体验。

核心优势
• 全模态模型及 Harness 升级：提供文本生成、图像生成、视频生成、向量化等能力模型，新增联网搜
  索等专属 Harness。
• 量大管饱性价比高：灵活提供 Small、Medium、Large、Max 四档套餐，兼顾大容量与高性价比，相较
  于后付费模式，享受更高折扣。
• 兼容主流编程与Agent工具：多生态兼容，无缝接入 OpenClaw、Hermes Agent、Claude Code、
  OpenCode 等主流编程及 Agent 工具。
• 包月省心管理：包月形式订阅，减少预算管理负担。
• 用量清晰可查：采用 Agent 燃料值（Agent Fuel Point，后简称 AFP）作为统一用量单位，额度用量清
  晰可查。

额度刷新规则
套餐额度在时间周期内耗尽后，需要等待下一个周期自动恢复额度，不会消耗其他资源包或账户余额。

• 日限额：每日 00:00:00 重置日限额（仅限视觉模型）。
• 月限额：每订阅月第 1 日 00:00:00 重置月限额。

积分计费机制（AFP）

AFP 定义
Agent 燃料值（Agent Fuel Point，简称 AFP）是 Agent Plan 套餐的统一用量计费单位，用于量化智能体
（Agent）资源的消耗。

抵扣公式
单次请求 AFP 消耗：

• 文本生成模型、向量化模型： (输入 token * 输入抵扣系数 + 输出 token * 输出抵扣系数) / 10,000
• 视频生成模型： 消耗的原始 token / 10,000 * 抵扣系数
• 图片生成模型： 成功生成的图片张数 * 抵扣系数


     注意
     生成视频预估消耗的 token 可参见价格示例                    中 token 用量估算公式。

Harness
联网搜索（Beta版）：本期不消耗套餐内AFP，根据订阅套餐会赠送一定的免费额度，支持开启超额后付

抵扣示例
• 文本生成模型示例：当模型设置为 doubao-seed-2.0-code ，某次请求输入为 50k token，输出为 0.5k
  token。


 Plain

    本次 AFP 消耗
    = (输入 token * 输入抵扣系数 + 输出 token * 输出抵扣系数) / 10,000
    = (50000 * 2.5 + 500 * 2.5) / 10000
    = 12.625 AFP


• 视频生成模型示例：当模型设置为 doubao-seedance-2.0-fast，某次视频任务输入包含视频，成功生
  成视频，消耗 150k token。


 Plain

    本次 AFP 消耗
    = 消耗的原始 token / 10000 * 抵扣系数
    = 150000 / 10000 * 110
    = 1650 AFP


• 图片生成模型示例：当模型设置为 doubao-seedream-5.0-lite，成功生成一张图片，消耗 99 AFP。


订阅规则

购买限制
单次下单套餐时长不能超过12个月，存量套餐时长 + 新购套餐时长不能超过24个月。

续费规则
• 自动续费：若您在下单时勾选自动续费，即连续包月，每次默认续费 1 个月，到期会自动扣除下一个
  月的套餐费用。

• 手动续费：若您在下单时没有勾选自动续费，可在开通管理                  进行续费操作。


升配规则
套餐有效期不变，补齐升配套餐的差价，即可升配，可在开通管理                     进行升配操作。套餐仅支持升配，
不支持降配。

• 差价计算公式
    升配需补差价金额 = (升配套餐月价 - 原套餐月价) / 30 天 * 套餐剩余时长
• 额度折算规则
   ◦ 月限额： 升配后当月可用额度 = 升配套餐月额度 * 当月剩余时长占比 + 原套餐月额度 * 当月已用时长占比
   ◦ 5小时限额与周限额：升配完成后，5小时限额、周限额均直接为升配套餐对应的限额。


退订规则
支持非七天无理由自助退订，退订说明及退款计算公式可详见非七天无理由退订说明                    。具体操作如
下：

1. 进入火山引擎费用中心-退订管理          。
2. 在非七天无理由退订页签，在产品列过滤火山方舟订阅套餐，找到要退订的套餐，在操作列单击退
   订，根据界面提示完成套餐退订。

• 您已正确安装 OpenCode，如未，请参见以下操作完成软件安装。
  前提条件：安装 Node.js 18 或更新版本 。
  在命令行界面，执行以下命令安装 OpenCode。


    Bash

       npm install -g opencode-ai


   安装结束后，执行以下命令查看安装结果，若显示版本号则安装成功。


    Bash

       opencode --version




二、配置 OpenCode

方式 1：自动化助手（推荐）
Ark Helper 是一个编码工具助手，支持快速配置选择的工具接入 Agent Plan。安装并运行该助手，根据界
面提示操作可自动完成工具配置，降低手动配置的时间成本和出错风险。


     注意
    • Ark Helper 仅支持 MacOS、Linux 系统，暂不支持 Windows 系统。
    • 以下配置步骤及截图为 Ark Helper 首次使用指引；非首次使用请按界面提示完成套餐配置和工
      具配置。


1. 执行以下命令安装 Ark Helper。


    Bash

       curl -fsSL https://lf3-static.bytednsdoc.com/obj/eden-cn/ylwslo-yrh/ljhwZthlaukjlkulzlp/install.sh
       | sh


   安装完成后，执行以下命令查看安装的版本号。

• <ARK_API_KEY> ：替换为您自己的专属 API Key                  。

3.6 OpenViking

OpenViking 是专为 AI 智能体（Agent）打造的上下文数据库，主要适用于多 Agent 协同、长期记忆管
理、复杂任务执行等场景。该数据库采用 viking:// 文件系统范式，将智能体的记忆、资源与技能进行统
一组织管理，依托分层加载机制按需供给上下文，在减少 Token 消耗的同时提升运行效率，结合目录式
检索优化信息召回效果。功能上，OpenViking 支持多租户、多用户及多 Agent 隔离，且能在会话结束后
自动沉淀长期记忆，实现智能体能力的持续积累与自我优化，既有效降低开发者的上下文管理成本，也
能显著提升 OpenClaw 等智能体的整体运行表现。
方舟 Agent Plan 支持在 OpenViking 中使用，可参考本文进行配置及使用。


     注意
     OpenViking 工具处于快速迭代阶段，本文使用的版本为 0.2.13，如果实际使用与以下步骤存在差
     异，可参见 OpenViking：AI 智能体的上下文数据库 。

     说明

        path="https://raw.githubusercontent.com/volcengine/OpenViking/refs/heads/main/

      # Explore the resource tree structure

      # Use glob to find markdown files
      glob_result = client.glob(pattern="**/*.md", uri=root_uri)
      if glob_result['matches']:

      # Wait for semantic processing to complete
      print("Wait for semantic processing...")
      client.wait_processed()

      # Get abstract and overview of the resource
      abstract = client.abstract(root_uri)
      overview = client.overview(root_uri)

      # Perform semantic search
      results = client.find("what is openviking", target_uri=root_uri)
      print("Search results:")
      for r in results.resources:

      # Close the client
      client.close()

4.1 接入向量化模型
方舟 Agent Plan 提供向量化模型，可以为工具提供语义向量能力，将对话、文档与任务信息等转换为高

相比传统关键词匹配，Embedding 检索在信息量大、对话长、资料分散的场景下，能够更准确地召回相
关内容，显著降低遗漏与误判。同时，Embedding 为记忆检索、知识库问答与工具调用提供统一的语义
检索层，帮助工具在不增加主模型推理成本的前提下，提升跨轮次上下文追踪能力与整体效果。

• 专属 Base URL：https://ark.cn-beijing.volces.com/api/plan/v3，Agent Plan 专属 Base URL 中包含 /
  plan ，请勿混用其他 Base URL。
• 专属 API Key：获取专属 API Key        ，其他方舟 API Key 如 Coding Plan API Key 无法在 Agent Plan 中使
  用。




• 支持的模型： doubao-embedding-vision （对应模型 doubao-embedding-vision-251215            ）


        注意
         ◦ 建议固定使用同一版本的向量化模型，请勿混用不同版本。

5. 配置 Harness
5.1 联网搜索（Beta版）
联网搜索是面向大模型构建的搜索服务，通过灵活 API 形式提供多垂类、多信源搜索能力，显著提升大模
型回答的可信度和知识面。

用户权益
订阅方舟 Agent Plan 个人版套餐，可享受联网搜索的限时免费调用权益。Agent Plan 到期时，下单附赠的
免费搜索额度也将回收。

• 个人版 Small 套餐：每月赠送 50 次免费搜索额度。
• 个人版 Medium 套餐：每月赠送 150 次免费搜索额度。
• 个人版 Large 套餐：每月赠送 400 次免费搜索额度。
• 个人版 Max 套餐：每月赠送 800 次免费搜索额度。


     说明
    • 免费搜索额度为限时活动，免费额度将在活动截止后调整。
    • 免费搜索额度每月1日刷新，刷新后已使用的免费额度清零。
    • 免费额度用尽后，可以在 Agent Plan 控制台       开启超额付费调用，开启后可以继续使用联网搜
      索服务。
    • 开启超额付费调用后，每月仍会优先消耗免费额度。

关于联网搜索

联网搜索免费额度用尽后，如何开通联网搜索后付费？
当月免费额度用尽后将无法继续使用，如果要继续使用，可以在 Agent Plan 控制台开启超额付费调用，
开启后会优先消耗免费额度，超额后将进行付费调用联网搜索服务，支持预付费包月和按量后付费两种
方式。详细计费信息可参见联网搜索产品计费 。

如何关闭联网搜索服务？
联网搜索是按量后付费型产品，当前官网无法主动关停服务。如有关停需求可提交工单申请                           。
