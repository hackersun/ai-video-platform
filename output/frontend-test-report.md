## 五、发现的Bug列表

### 🔴 Bug #1: 菜单显示不一致（严重）

**问题**: 只有Dashboard页面有顶部导航菜单，其他页面缺少导航

**影响页面**:
- /novels
- /tts
- /scripts
- /characters
- /videos

**预期行为**: 所有页面都应该有统一的顶部导航菜单

**修复建议**: 
1. 创建一个通用的Layout组件包含导航菜单
2. 在所有页面中使用该Layout组件
3. 或者使用Next.js的_layout.tsx文件

### 🔴 Bug #2: 菜单项缺失（严重）

**问题**: Dashboard的菜单缺少关键功能入口

**缺失菜单项**:
- 剧本
- 角色
- 视频
- 任务队列
- 分镜
- AI模型
- 设置

**修复建议**: 更新Dashboard页面的导航菜单，添加缺失的功能入口

### 🟡 Bug #3: 页面返回按钮不一致（中等）

**问题**: 有些页面使用"返回"按钮，但没有统一的导航方式

**影响**: 用户在不同页面间切换不方便

## 六、修复建议

### 6.1 短期修复（1-2天）

1. **创建通用导航组件**
   ```tsx
   // components/layout/MainLayout.tsx
   export function MainLayout({ children }) {
     return (
       <div>
         <TopNavigation />  {/* 统一的顶部导航 */}
         <main>{children}</main>
       </div>
     );
   }
   ```

2. **更新Dashboard菜单**
   添加缺失的菜单项：剧本、角色、视频、任务队列、分镜、AI模型、设置

3. **为所有页面添加导航**
   - novels页面
   - tts页面
   - scripts页面
   - characters页面
   - videos页面

### 6.2 中期优化（1周）

1. **响应式菜单设计**
   - 移动端汉堡菜单
   - 侧边栏导航（可选）

2. **权限控制**
   - 根据用户角色显示不同菜单
   - 免费版/专业版功能限制

3. **当前页面高亮**
