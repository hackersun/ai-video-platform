# 模型基础配置与租户隔离实施计划

## 目标锁定

让普通主测用户能快速复用系统供应商、模型和提示词基础目录，同时确保密钥、默认模型、生产组合及小说生产数据严格按用户隔离。

## 范围与约束

- 共享只读：系统供应商目录、模型目录、已发布系统提示词模板。
- 用户私有：供应商账号与密钥、默认模型绑定、生产组合、用户自建提示词草稿与版本。
- 业务私有：小说、章节、剧本、分镜、镜头及其生成任务。
- 不重置数据库，不迁移或覆盖现有用户数据，不暴露任何密钥明文。
- 不重构现有大文件；只修复经测试确认的授权或可用性缺口。

## 验收标准

1. 两个用户看到一致的系统供应商、模型和系统提示词基础目录。
2. 用户 B 无法看到、读取、修改或使用用户 A 的供应商连接、密钥、默认绑定和生产组合。
3. 用户 A 与用户 B 可设置不同默认模型，互不覆盖。
4. 用户 B 无法读取用户 A 的小说、章节、剧本、分镜和镜头。
5. 普通用户不能直接修改全局供应商或模型目录，只能配置自己的账号与默认模型。
6. API 和界面均不返回密钥明文；错误信息为中文且可操作。
7. 主测用户可从前端完成“选供应商目录 → 保存私有账号 → 选模型 → 设默认模型 → 查看实际提示词来源”。

## 执行步骤与验证

1. 记录当前表结构、接口查询条件和运行实例数据分布。
2. 增加双用户共享可见与私有隔离回归测试，并先确认失败点。
3. 最小修复目录维护权限、系统提示词可见性及发现的跨用户访问缺口。
4. 运行目标后端测试、前端类型检查/构建和浏览器双用户验收。
5. 部署到当前本地服务并复查主测用户完整配置链路。

## 决策点

用户已授权自主完成后续动作；仅在需要删除现有数据、重置密钥或产生真实模型费用时暂停。
