# Seedream 5.0 Pro 默认生图模型实施计划

## 执行契约

- 意图锁定：把火山方舟非 Lite 旗舰生图模型 `doubao-seedream-5-0-260128` 以“Seedream 5.0 Pro”接入产品目录，并在一次真实生图验证成功后设为 `sunqy` 的默认生图模型。
- 范围：模型目录、火山图像能力注册、任务默认路由、用户模型配置、前端可见性与默认状态验证。
- 非目标：不修复 arkcli SSO，不修改视频/TTS 默认模型，不做图像质量基准测试，不删除旧 MiniMax 回退配置。
- 安全约束：API Key 不进入源码、测试快照或命令输出；真实验证只生成一张图且失败不重试；验证成功前不切换默认。

## 实施步骤

1. 先补模型目录、请求模型标识和任务默认路由的失败测试。
2. 抽出火山生图模型目录，增加旗舰模型并更新注册表默认路由。
3. 运行定向后端测试与前端构建，确认兼容现有 4.5 / 5.0 Lite。
4. 重启服务，给 `sunqy` 创建非默认配置并发起一次真实生图连接测试。
5. 仅在实模成功后设为默认，通过 API 与前端页面核对“已验证 + 默认”状态。

## 验收标准

- `/api/v1/llm/models?provider=volcano` 返回 `doubao-seedream-5-0-260128`，类型为 `image-generation`。
- 火山生图请求把该完整模型 ID 原样传给 `/images/generations`。
- `character_image` 与 `scene_reference_image` 的注册表默认模型指向旗舰版，4.5 保留为回退。
- `sunqy` 的配置测试成功后，该配置成为唯一默认生图配置；原 MiniMax 配置仍保留。
- 前端模型配置页可见旗舰模型、成功状态和默认状态；前后端健康检查通过。
