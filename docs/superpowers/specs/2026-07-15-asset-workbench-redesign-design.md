# 资产工作台重设计

## Intent Lock

把资产页从“向导和表单驱动的超长页面”改为“查找、判断、批量维护优先的制片资产工作台”，不改变现有资产 API、持久化数据和安全限制。

## Visual Target

- 选定视觉：方案 1。
- 源图：`/Users/sunqinyue/.codex/generated_images/019f4ca9-c6c3-7701-9e09-0cf4fc148093/exec-cffc50a5-4724-423d-8009-04abfc814117.png`
- 桌面基准：1440 × 1024。
- 延续当前深色海军蓝、紫色品牌、顶部导航和 Lucide 图标体系。

## Primary User And Outcome

主要用户是多章节动漫的制片人员。进入资产页后，三秒内应能回答：

1. 当前小说有哪些资产；
2. 哪些资产失败、未锁定或待定稿；
3. 选中资产的版本、作用域、绑定对象和引用情况；
4. 如何批量锁定、改标签、改作用域或归档。

## Information Architecture

首屏由四个固定区域组成：

1. 顶部上下文栏：小说、制作范围、搜索和刷新。
2. 左侧智能集合：全部、待处理、生成失败、待定稿、已锁定，以及角色、场景、道具分类。
3. 中部资产表：复选框、缩略图、名称/对象、类型/视图、状态、引用、更新时间和一个上下文动作。
4. 右侧检查器：大图预览、版本、作用域、绑定对象、一致性/失败信息，以及预览、编辑和更多操作。

选中资产后，底部显示批量操作栏。AI 多视图向导和新建/编辑表单继续保留，但放在工作台之后，不再占据首屏。

## Behavior

- 智能集合仅在已加载资产上做即时筛选，不创建第二套服务端查询规则。
- 行点击更新右侧检查器；复选框只更新批量选择，不触发行点击。
- 生成失败资产显示人能读懂的失败原因和重试入口。
- 锁定、定稿、公开、引用次数和作用域沿用现有字段。
- 危险归档保持二次确认；不确定状态不新增自动重试。
- 现有深链接参数 `novel_id/entity_type/entity_id/view_key/action/source` 继续生效。

## Architecture

- `frontend/src/app/assets/page.tsx` 继续拥有数据加载和现有命令处理，但不再拥有新工作台的展示细节。
- 新增 `frontend/src/features/assets/`，按工具栏、智能集合、资产表、检查器和批量栏拆分。
- 新组件均为受控展示组件，不复制 API 客户端和业务安全规则。
- 原 2645 行热点文件必须净减少，不能继续增长。

## Acceptance Criteria

- 首屏出现“资产工作台”、智能集合、资产表和检查器。
- 搜索输入、小说选择和刷新仍调用现有页面状态/加载函数。
- 点击“生成失败”只显示失败资产。
- 选择一项后检查器展示对应资产；选择多项后显示批量栏。
- 失败资产有明确错误原因与“重试”操作。
- 新建、编辑、锁定/解锁、批量锁定/解锁、标签、作用域、归档和版本历史入口仍可达。
- 1440 × 1024 与 390 × 844 不出现横向页面溢出。
- 现有资产向导深链接和测试契约保持可用。
