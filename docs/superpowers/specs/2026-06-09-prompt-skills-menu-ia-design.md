# Prompt 技能库与流程型菜单设计

## 目标

采用已确认的 B 方案，把平台入口重组为“流程型导航”，并补齐一套可直接使用的内置 Prompt 技能库，覆盖从小说创建到视频出片的主要 AI 环节。

## 范围

- Prompt 技能不再默认为空。系统提供内置标准技能，用户可克隆、编辑、预览、激活和回滚。
- 生成链路默认使用内置技能；当用户为同一任务激活自定义技能时，自定义技能覆盖内置默认技能。
- 菜单按个人/小团队创作流程分组：工作台、极速向导、作品、内容创作、资产设定、生产出片、配置、团队。
- 本次只重组导航配置和 Prompt 技能任务覆盖，不重写各业务页面。

## 标准技能任务

- `novel_generation`：小说创建
- `chapter_writing`：章节创建
- `script_generation`：剧本创建
- `storyboard_generation`：分镜创建
- `shot_prompt`：镜头创建
- `shot_video`：视频创建
- `character_image`：头像/角色图
- `scene_reference_image`：场景图
- `prop_image`：道具图
- `novel_cover`：封面图
- `tts_dialogue`：角色配音
- `shot_audio_video`：音视频直生
- `consistency_review`：一致性审查
- `repair_suggestion`：返修建议

## 菜单分组

- 顶部高频：工作台、极速向导、作品
- 内容创作：作品/小说、章节、剧本、分镜、镜头
- 资产设定：Story Bible、角色、实体、资产库、模板库
- 生产出片：视频生成、语音合成、字幕、时间线、音视频合成、任务队列
- 配置：Prompt 技能、AI 模型、生产适配、设置、数据分析
- 协作：团队

## 测试标准

- 后端测试验证内置技能数量、任务覆盖、非空内容、幂等补齐、用户技能覆盖内置技能。
- 前端 E2E 验证 Prompt 技能页出现流程分组和新增任务类型。
- 前端 E2E 验证顶部导航按 B 方案分组展示，旧的一线混杂入口不再直接铺满顶部。
