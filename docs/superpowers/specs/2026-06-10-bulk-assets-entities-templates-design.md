# 资产实体模板批量维护设计说明

## 目标

为资产、实体、创作模板、提示词/技能模板补齐批量维护能力，并让资产与实体支持按小说、章节、剧本来源重新抽取。实现时保留现有 Web 平台底座，复用已有选择态、提示词技能模板和资产生成链路，避免引入新的重型工作流。

## 范围

本次纳入四类对象：

- 资产库：支持批量锁定、解锁、归档、作用域调整；支持选中实体资产后单点重生成。
- 实体库：支持批量确认、取消确认、删除、作用域调整；支持按小说、章节、剧本重新抽取。
- 创作模板库：支持批量删除用户模板、批量复制预置模板、批量更新分类、标签、公开状态。
- 提示词/技能模板：支持批量删除未激活自定义模板、批量克隆、批量更新标签；激活规则仍保持每个任务只允许一个用户激活模板生效。

## 重抽模式

实体和资产重抽提供三种模式：

- 追加抽取：保留现有实体，仅新增缺失实体。
- 覆盖更新：按实体类型和规范名匹配，更新描述、别名、外观、证据、置信度，不替换实体 ID。
- 删除后重抽：先清理选中范围内实体和相关非锁定资产，再重新抽取。

单点选中实体时，允许只重抽该实体相关资产包，不强制重抽全书或全剧本实体。

## 约束

生产模式下：

- 锁定或定稿资产不能批量归档，必须先解锁。
- 被引用资产不能硬删除，本次仍执行软删除或给出阻断。
- 内置提示词/技能模板不可删除，只能克隆。
- 激活中的提示词/技能模板不可删除，需要先激活同任务下的其它模板或取消激活。
- 预置创作模板不可删除，只能复制到用户模板库。

测试模式下：

- 可通过请求字段显式传入跳过约束开关。
- 响应必须返回 warnings，说明跳过了哪些生产限制。
- 前端需要显示清晰提示，用户确认后才执行。

## 前端交互

批量维护入口统一使用“选择后出现工具条”的方式，不新增复杂后台任务页。

- 资产页复用已有资产勾选状态，补齐批量解锁、批量归档、批量作用域调整入口。
- 实体页复用已有实体勾选状态，补齐批量删除、批量作用域调整、按当前筛选来源重抽入口。
- 创作模板页新增多选态，预置模板只显示“批量复制”，用户模板显示“批量删除/改标签/改分类/公开状态”。
- 提示词/技能页新增多选态，内置模板只允许克隆，自定义激活模板删除时显示阻断原因。

## 后端接口

新增接口应尽量贴近现有资源：

- `POST /assets/bulk-action`
- `POST /story-bibles/entities/bulk-action`
- `POST /story-bibles/entities/reextract`
- `POST /templates/bulk-action`
- `POST /prompt-skills/bulk-action`

接口返回统一包含：

- `updated_count`
- `deleted_count`
- `created_count`
- `skipped`
- `warnings`
- 对应资源列表

## 风险

主要风险是实体 ID 变化导致镜头、资产、视频链路引用失效。因此默认模式必须优先覆盖更新，不替换实体 ID。只有用户明确选择“删除后重抽”时才清理旧数据。

资产生成接口可能不适合一次镜头带入过多实体参考图。本次不扩大视频生成接口参数，只把重抽后的资产整理为实体资产包，后续视频生成仍由预检阶段选择最关键参考图。

## 验收

- 后端单元测试覆盖批量动作、生产约束、测试模式跳过、覆盖重抽不换 ID。
- 前端 E2E 覆盖资产、实体、创作模板、提示词模板的批量工具条。
- `npm run build` 通过。
- 相关 Playwright 用例通过。
