## 差异审查

- 范围只包含发布证明 JSON、校验器、合同测试、CI job、发布门禁说明、计划和证据文档。
- 不修改 HTTP API、数据库表、供应商请求、计费状态、媒体文件或前端页面。
- 本地证据路径必须留在仓库内且实际存在；外部证据只接受 HTTPS。
- `main` 严格模式会拒绝非 `releases` 来源、阻塞项、过期证明和缺失证据。
- 机器校验不能证明人工签字真实性；CODEOWNERS 和发布负责人审核继续是正式发布的必要条件。

## 发布判断

本批远端 CI 全部通过后可以合入 `dev` 并提升到 `releases` 候选线，同时把 `commercial-release-gate` 加入受保护分支必需检查。

当前 G2-G8 仍阻塞，因此禁止提升到 `main`。只有在预发布安全、恢复、任务媒体、三章付费实模、真实账单、产品 UAT、告警和回滚证据全部补齐后，才能把对应状态改为 `pass` 并重新走完整审核。
