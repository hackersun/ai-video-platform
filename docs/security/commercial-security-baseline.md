# 商业安全基线

## 生产配置

- 生产环境缺少 JWT、数据库、对象存储或供应商密钥时必须启动失败。
- `DEV_MODE` 仅允许显式本地环境启用，生产默认关闭。
- 数据库、Redis、消息队列、MinIO、Neo4j 等不得使用示例密码。
- 内部基础设施端口默认不暴露公网。
- 日志不得输出 API Key、Authorization、Cookie、重置令牌和完整供应商响应中的敏感字段。

## 身份与会话

- 密码最少 12 位，并检查常见弱密码。
- 注册必须验证邮箱；异常注册和登录需要限流或人机验证。
- Access Token 短时有效，通过 Secure、HttpOnly、SameSite Cookie 传输。
- Refresh Token 每次使用后轮换，可按设备和用户撤销。
- 修改密码、权限和敏感设置后撤销相关会话。
- 管理员和财务角色支持 MFA，企业客户预留 SSO/OIDC。

## 权限模型

目标层级：

```text
平台 -> 组织 -> 工作区 -> 项目 -> 资源
```

基础角色：

- 平台管理员：平台配置和安全运维，不默认访问客户正文。
- 组织所有者：成员、账单、组织策略。
- 工作区管理员：项目和成员授权。
- 编辑：创建和修改生产内容。
- 审核：批准实体、资产、成片和发布。
- 财务：查看账单、额度和对账，不编辑内容。
- 只读：查看已授权项目。

每个 API 必须在权限矩阵中标记匿名、登录用户、项目角色或平台角色。仅依赖前端隐藏按钮不构成授权。

## Web 与 API

- CORS 使用明确来源，禁止通配来源与凭据组合。
- Cookie 模式下为状态改变请求提供 CSRF 防护。
- 响应启用 CSP、HSTS、X-Content-Type-Options、Referrer-Policy 和 frame 限制。
- 全局异常只返回稳定中文错误码和用户可行动说明，内部堆栈只进入受控日志。
- 对登录、注册、找回、生成、轮询、上传和管理接口分别限流。
- 上传校验 MIME、扩展名、大小、图像解码和恶意文件。

## 数据与媒体

- 数据按用户、组织和项目强制隔离。
- 媒体默认私有，访问使用短时签名 URL。
- 数据库和对象存储均加密，备份单独加密并限制访问。
- 定义正文、提示词、媒体、日志、账单和审计记录的保留周期。
- 支持用户数据导出、删除申请和法律保留。
- 记录训练、参考图、字体、音乐和素材的版权来源与授权范围。

## 供应商与模型

- 供应商 API Key 只能由后端读取，不允许用户请求携带任意平台密钥。
- 每个模型绑定记录账号、用途、能力、地区、价格和验证状态。
- 生产调用必须通过模型目录和能力契约，不允许硬编码旁路。
- 供应商错误经过脱敏和中文映射后返回。
- 参考资产、提示词和生成结果的跨境与保留政策必须可配置。

## 审计事件

至少记录：登录失败、会话撤销、成员与角色变化、模型凭据和绑定变化、提示词发布、额度调整、任务重试、人工审核、发布、退款、数据导出和删除。

审计记录包含操作者、组织、项目、动作、对象、时间、请求 ID、前后值摘要和结果；审计日志不可由普通业务用户修改。

## 验证

- 自动化依赖、Secret、SAST 和容器扫描。
- 权限矩阵正向与越权测试。
- 会话轮换、撤销、CSRF、CORS、限流和异常脱敏测试。
- 每个正式版本进行一次备份恢复和一次关键业务安全回归。
