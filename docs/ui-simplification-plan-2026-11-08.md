## 一、核心发现

1. **主路径其实已经很短，但被大量并列入口淹没。** 从注册到拿到视频，模拟模式下最少只要 **10 次点击**；可新手看到的入口远不止这些：导航 5 个主菜单加“高级工具”下 9 项，代码里共有 **50 个页面路由**。小说详情页同时摆着：一键生成、“AI 下一步”（分析制作资产 / 管理章节 / 核对剧本）、每章一个“生成剧本”、底部 4 块（视频生成 / 语音合成 / 音视频合成 / 封面生成）、6 个 Tab。新手分不清该点哪个。
2. **配置有两套“入门路径”，互相打架。** “模型设置”只要一页填 Key；“模型中心 → 全局概览”还在展示“四步完成模型接入”（保存账号 → 添加模型 → 验证 → 设为默认），并且一上来就是 3 条“生产阻塞项”（截图 03-model-center-overview）。两套口径会让新手以为必须走完四步。
3. **配置页里还藏着几个必做决定。** 用真实 Key 时，除了粘贴 Key，还要：填“语音 App ID”（火山必填）、勾选“开启真实模型调用”、理解“账户上限 / 单次流水线上限”、先点“保存”再点“测试连接”。少做任何一步，生成就会失败或卡住，但页面没有一步一步的引导。
4. **专业术语多。** 统计到的专业词在全站去重后超过 80 个。新手路径上最显眼的有：Story Bible、整书计划、分镜、资产、一致性、TTS、Deterministic text/image/video/tts（模型卡片直接显示内部名）、供应商、凭证、组合预设、认证、证据、契约、就绪度、阻塞。工作室 / AI 制片页一页就有 27 / 21 个术语（门禁、漂移、状态机、Seed、Readiness 75、Final Quality 等）。
5. **页面上还有几个没处理干净的地方。**
   - 导入 txt 时如果不填标题，书名会变成正文第一段（截图 08，标题是两行长句）。
   - 镜头管理页显示 `object Object`（20-shots）。
   - 数据分析页露出 `mock`、`false`、`api` 这类原始字段（20-analytics）。
   - 任务中心直接显示 UUID 列表（20-jobs）。
   - 模型设置 / 账号页文字里带 `live-text-<uuid>`、`contract-text` 这类内部 ID。
   - 团队页、成片播放页空白，只有一个“重试”（20-teams、20-media-player）。
   - 用模拟模式时，一键生成会多弹一个“模拟模式确认”（12-one-click-confirm）。
6. **小说的入口有两个。** “小说管理”页有“导入”，另有 /novels/new 新建页，有 7 个字段、57 个按钮，包括封面风格、AI 简介、角色关联。可对新手来说，只需要“粘贴或上传正文”一个动作。

## 三、逐页问题与建议

分级说明：**合并** = 并入已有入口；**折叠** = 默认收进“高级”；**自动** = 由系统代替用户决定；**白话** = 改用户能懂的说法；**删除** = 去掉重复入口（能力保留在唯一入口）。

### 1. 注册后引导（01-after-register → /llm-config?welcome=1）
- 现状：注册后直接进模型设置，页面上同时有黄色提示、模拟模式卡、供应商、Key、4 张模型卡、费用卡、保存和测试按钮。第一屏就有 11 个控件。
- 建议：
  - 【自动 / 折叠】欢迎态顶部只放两个大按钮：“先免费试用（演示素材）”和“我有火山 Key”。选择后再展开对应内容。4 张模型卡默认折叠成一行“已为你选好推荐模型 · 修改”。
  - 【自动】试用模式点一次就保存并完成自检，然后直接跳到“小说”页的导入框。现在要依次点“使用模拟模式”“测试连接”，再手动去导航点“小说”。

### 2. 模型设置（简易，02/04）
- 问题：
  - Key、App ID、开启真实调用、两个金额上限、保存、测试，全部同级平铺。
  - “保存”和“测试连接”是两个动作。
  - 模型下拉显示 `Deterministic text` 这类内部名。
- 建议：
  - 【合并】“保存”时自动测试，只留一个按钮“保存并检测”。
  - 【自动】填了 Key 并检测通过后，默认开启真实调用，上限默认 ¥50 / 次、¥200 / 账户，在按钮旁用一行字说明。“开启真实模型调用”勾选框和两个上限输入框折进“费用上限（可选）”。
  - 【白话】
    - 模拟配置的名字显示为“演示文本 / 演示图片 / 演示视频 / 演示配音”。
    - “供应商”改成“服务商”。
    - “语音 App ID”的说明写成“在火山控制台 → 语音技术 → 应用管理里复制”，并放一个跳转链接。
  - 【自动】检测发现缺 App ID 时，只把这一个输入框高亮出来，不在一开始就展示。

### 3. 模型中心 / 高级设置（03-*）
- 问题：
  - 和“模型设置”是两条并行的入门路径。
  - 全局概览上来就是“四步完成模型接入”和“生产阻塞项”。
  - 侧栏 7 个分区：供应商账号、模型目录、默认模型、组合预设、提示词模板、测试实验室，外加按能力查看。新手看不懂。
- 建议：
  - 【删除重复入口】去掉概览里的“四步完成模型接入”，换成一句“日常使用只需在『模型设置』填 Key；这里供多账号、私有网关、提示词调优使用”。连接页已经有这条提示，两处统一。
  - 【白话】
    - 生产阻塞项 → 建议优化项。
    - 组合预设 → 生成方案。
    - 认证 / 证据 → 检测记录。
    - 就绪度 → 可用状态。
  - 【折叠】“测试实验室”“提示词模板”只在打开“专业模式”开关后显示。开关放在模型中心右上角，用户自己的偏好存在 localStorage。
  - 导航入口：“高级设置”只从“模型设置”页右上角进入，这一点现在已经是这样。

### 4. 小说管理 / 导入（05、07）
- 问题：
  - 新建（/novels/new，57 个按钮）和导入是两个入口。
  - 导入时不填标题，书名会变成正文第一段。
  - 不能直接粘贴文本，必须先存成 txt 文件。
- 建议：
  - 【合并】小说页主区域只放一个大文本框“粘贴小说正文或拖入 txt”，带题材下拉（可选）和“开始”按钮。“新建空白小说（自己写）”放到“更多”里。/novels/new 页面保留给自己写的用户，但不再作为首要入口。
  - 【自动】标题取第一行；如果第一行超过 30 字或者像正文，改用文件名，粘贴的情况用“未命名小说-日期”，并允许在详情页点标题修改。
  - 【自动】导入成功后，详情页的一键生成按钮直接高亮成下一步，并且只提示这一步。

### 5. 新建小说（06）
- 问题：AI 简介模型、封面模型、封面风格、角色关联同时展开，按钮多达 57 个，大部分是风格芯片。
- 建议：【折叠】只保留标题、正文/简介两项；“封面与风格”“角色关联”“使用的模型”折叠成“更多设置”。模型卡片改成一行文字“使用模型设置中的默认模型”。

### 6. 小说详情 / 章节 / 角色（08–11）
- 问题：
  - 6 个 Tab：章节、整书计划、角色、剧本、Story Bible、设置。
  - “AI 下一步”推荐的是“分析制作资产”，和一键生成冲突。
  - 底部 4 块（视频生成 / 语音合成 / 音视频合成 / 封面生成）是旧式分步入口。
  - 每章都有“生成剧本”。
  - 统计卡片：章节、角色、剧本、分镜、视频、设定。
  - “一致性状态：建议生成 Story Bible”。
- 建议：
  - 【合并】顶部只保留一张“生成卡”：还没生成时，显示一键生成按钮，加一句“约 x 分钟，自动完成剧本、画面、配音和拼接”；生成中显示进度卡；生成完显示播放器、下载、发布。“AI 下一步”在一键模式下隐藏。
  - 【删除重复入口】底部 4 块分步入口移进“更多 → 分步制作（专业）”。每章的“生成剧本”改成在“分步制作”里统一处理，章节列表只保留编辑和查看。
  - 【折叠】Tab 只默认显示“章节”和“角色”；整书计划、剧本、Story Bible、设置放进“专业”Tab 组，或者用“更多”展开。
  - 【白话】
    - Story Bible → 故事设定。
    - 整书计划 → 分集计划。
    - 分镜 → 画面脚本。
    - 资产 → 角色与场景图。
    - 一致性 → 前后统一。
  - 【白话】“使用全局模型设置：文本 Deterministic text…”这一行改成“使用默认模型（演示模式）· 修改”。

### 7. 一键生成与进度（12–14）
- 问题：
  - 模拟模式多一次确认，真实模式也有一次确认。
  - 进度条 9 段：已提交、准备整书计划、生成剧本和分镜、生成画面和配音、渲染各集、拼接整书、质量检查、发布中、已完成。新手看不懂。
- 建议：
  - 【合并】确认框只在真实计费时出现，并且直接写清楚预计费用上限。模拟模式不再确认，因为不扣费。
  - 【白话】进度合并成 4 段：准备 → 写剧本 → 做画面和配音 → 合成视频。细节放进“查看详情”展开。
  - 已完成：保持现在的播放器加“查看发布 / 下载视频”，这部分已经很简洁。

### 8. 成片 / 下载 / 发布（20-synthesis）
- 问题：/synthesis 叫“音视频合成”，页面上有选视频、选音频、合成设置、合成历史、发布记录，8 个字段、25 个按钮，导航名却叫“成片”。
- 建议：
  - 【折叠】“成片”页默认只显示“我的成片”列表（播放 / 下载 / 发布 / 删除）。“手动合成音视频”收进“专业：手动合成”折叠区。

### 未决项

1. 生产环境没有“免费试用”。演示模式只在测试环境可用（`simulation_available`），生产环境注册后直接进入 Key 表单。要在生产环境提供试用，需要另定产品方案，比如赠送少量额度或内置演示样片。
2. 测试环境的假供应商会让任何 Key 都检测通过，因此在测试环境填 Key 也会自动开启真实调用。这符合设计，也不会产生真实费用。
3. 模型中心（高级）里的供应商列表仍会显示测试遗留数据（例如 `live-text-<uuid>`）。这属于高级页和开发数据库的问题，本轮没有处理。
4. 试用模式仍会弹“模拟模式确认”（计划在 P1-1 去掉），所以试用路线是 7 次点击，比方案目标多 1 次。
