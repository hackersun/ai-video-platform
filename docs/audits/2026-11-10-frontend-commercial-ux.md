## 7. 验收标准（商用前端）

### 7.1 新手路径

- [ ] **试用**（若环境支持）：注册到播放器可见 ≤ **5 次点击**，必须决定 ≤ **1**。  
- [ ] **真实 Key**：注册到「模型全部就绪」≤ **4 次点击**（含粘贴 Key），一键前费用确认展示上限。  
- [ ] 主路径不出现：Production Bible、Series Studio、Readiness、Deterministic、Story Bible（无中文）、契约、门禁、状态机。  
- [ ] 顶栏默认可见入口 ≤ **3**（小说/成片/模型设置）；高级工具需二次点击。  
- [ ] 手机宽度下可进入模型设置，无需横屏猜图标。

### 7.2 一功能一入口

- [ ] Playwright：顶栏每个功能唯一规范入口（现有用例保持）。  
- [ ] 「开始创作」类文案全部指向 `/novels`（或欢迎模型设置），不出现「向导」作为默认 CTA。  
- [ ] 小说详情默认区仅一个生成主按钮；分步能力仅「更多 / 专业」。

### 7.3 可靠性相关 UI（与后端审计配合）

- [ ] 排队 / 暂停 / 失败 / 取消文案可懂，带「去处理」且链接有效。  
- [ ] 下载带 `download=1`；发布页聚焦卡片可播。  
- [ ] 错误不展示原始 JSON / 内部 code（blocker 映射覆盖率抽检）。

### 7.4 回归

- [ ] 相关 Playwright（onboarding / paste-import / novel-workbench / pipeline / synthesis）全绿。  
- [ ] 不放宽断言；不新增页面。
