# 生产操作与验收指南

## 适用版本

适用于 `v1.0.0-rc.1` 及 2026-08-18 远程 H3 实模补丁。公网入口为 `http://112.6.25.76:8080`，运维入口与公网入口必须分别验证。

## 前端操作顺序

1. 使用测试用户登录，确认工作台能读取该用户自己的小说、工作流与模型绑定。
2. 在“供应商账号”确认 MiniMax 连接属于当前用户且认证成功；页面不得显示或返回完整密钥。
3. 在“默认模型”确认“镜头视频生成”使用 MiniMax H3；在提示词使用地图确认小说、实体、剧本、分镜和镜头各环节均有可发布模板。
4. 创建或选择小说与章节，生成 Story Bible、角色/场景/道具、剧本、分镜和镜头。实体必须与当前小说绑定，不得混入其他用户或其他小说数据。
5. 生成并锁定参考图，执行一致性预检；只有“阻塞项 0”时才能提交视频。
6. 提交 H3 视频任务，检查任务状态、模型执行快照、参考图传递、镜头回写和公网播放。
7. 创建字幕轨并执行 FFmpeg 合成；只有 `render_status=rendered`、`is_publishable=true` 且公网文件可播放时才算成片完成。

## 本版本验收样例

- 小说：九霄镜契·公网实模验收。
- 章节：第一章 玄镜照山门。
- 原始视频：`http://112.6.25.76:8080/static/generated/videos/video-cdf97965-aad9829161ee4524be7af82204700a5a.mp4`。
- 中文字幕成片：`http://112.6.25.76:8080/static/generated/synthesis/final-2040f5fd2ca54464b95dd21a0fd22272.mp4`。
- 验收要求：HTTP 200；H.264 1344×768；AAC；4.458 秒；第 2 秒画面可见完整中文旁白字幕。

## 问题处理口径

- 前端只显示中文、直白的处理建议；供应商原始英文错误放入“技术详情”，不能直接作为主提示。
- “配置成功”不等于“实模成功”。必须同时有连接认证、任务提交、轮询成功、文件持久化和公网播放证据。
- 宿主机无法访问自身公网地址时，使用外部客户端复测媒体 URL；不得因为回环网络失败而删除已验证资产。
- 失败草稿优先停用而非物理删除，正式业务数据、媒体卷和用户密钥不得随应用升级清理。

## 验收命令

```bash
curl -fsS http://112.6.25.76:8080/healthz
ffprobe -v error -show_entries format=duration:stream=codec_name,width,height \
  http://112.6.25.76:8080/static/generated/synthesis/final-2040f5fd2ca54464b95dd21a0fd22272.mp4
```

最终还需在浏览器中完成登录、工作台加载、模型可见性、任务状态和视频播放检查；接口通过不能代替交互验收。

## 实体提取默认提示词验收（2026-08-18）

- “角色提取”必须命中系统共享的“标准角色提取技能”，子阶段为 `character`。
- “场景/道具提取”必须命中系统共享的“标准场景/道具提取技能”，子阶段为 `scene_prop`。
- 两个模板共用任务键 `entity_extraction`，但不能再共用笼统的 `analysis` 阶段；否则使用地图会显示“内置兜底”。
- 登录后打开“提示词使用地图”，确认汇总中的 `internal_fallback` 为 0；字幕和成片合成显示“无需提示词”属于正常状态。
- “对白配音”若显示模型配置异常，应配置语音模型，不能通过增加提示词模板掩盖模型缺失。
